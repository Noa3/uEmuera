Used after a CASEELSE statement:  = CASEELSE文より後で
Used after an ELSE statement:  = ELSE文より後で
Used outside IF~ENDIF:  = IF～ENDIFの外で
Used outside REPEAT, FOR, WHILE, DO:  = REPEAT, FOR, WHILE, DOの中以外で
Used outside SELECTCASE~ENDSELECT:  = SELECTCASE～ENDSELECTの外で
Values on the right side of the assignment cannot be omitted = 代入式の右辺の値は省略できません
Variable  = ローカル変数でない変数
Variable name  = 変数名
Variables of different types cannot be referenced = 型が異なる変数は参照できません
Variables with different numbers of dimensions cannot be referenced = 次元数が異なる変数は参照できません
Variables with the CONST keyword cannot be multidimensional arrays = CONSTキーワードが指定された変数を多次元配列にはできません
When omitting the elements of the target variable  = 対象となる変数
