## What is uEmuera?

**uEmuera** is a Unity 6 port of [Emuera](https://osdn.net/projects/emuera/), a text-based game engine that runs ERA script games. This fork adds:

- **Cross-platform support** — Windows, Linux, Android
- **Modern engine** — Unity 6 with IL2CPP, Burst compiler, incremental GC
- **Extended commands** — EM/EE (MultipleEx/EnhanceEx) extensions
- **Full audio** — WAV playback with `PLAYSOUND`, `PLAYBGM`, etc.
- **Modern UI** — Dark theme, pixel-perfect rendering, optional CRT effect

## Project Origin

uEmuera is based on:
- [xerysherry/uEmuera](https://github.com/xerysherry/uEmuera) — original Unity port
- [emuera1824v15](https://osdn.net/projects/emuera/) — base Emuera source code
- EM/EE extensions — Emuera MultipleEx/EnhanceEx community patches
